<!-- lang:hi -->
**सर्च इंजन** (जैसे Google) में कुछ **शब्द** लिखकर हम जानकारी खोजते हैं।

- ज़्यादा साफ़ शब्द लिखें: *how to write a CV for freshers* सिर्फ़ *CV* से बेहतर है।
- पहले नतीजे पर आँख मूँदकर भरोसा न करें। एक से ज़्यादा **भरोसेमंद** साइट देखें।
- सुरक्षित वेबसाइट का पता **https://** से शुरू होता है।
<!-- lang:en -->
In a **search engine** (like Google) you type a few **words** to find information.

- Type clearer words: *how to write a CV for freshers* is better than just *CV*.
- Do not trust the first result blindly. Check more than one **trusted** site.
- A secure website address starts with **https://**.
