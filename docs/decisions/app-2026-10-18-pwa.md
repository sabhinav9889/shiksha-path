# Progressive Web App, not native

**Status:** decided · 2026-10-18 · spec §4

## Context

Students use low-end Android phones; labs use laptops. No budget for two codebases or app-store
publishing.

## Decision

One Progressive Web App for phones, tablets and lab laptops: installable, offline-capable, updated
without an app store.

## Consequences

- One codebase; instant updates; works on lab PCs.
- Offline storage can be cleared by the browser, so we request persistent storage and sync often.
- Installed name/icon updates (branding) can lag a few days on Android.

Alternatives rejected: native Android (store releases, a second product for laptops), WhatsApp + web
(no offline structure or real progress tracking).
